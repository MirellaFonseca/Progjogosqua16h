# 🎮 ProgJogosQua16h - Curso de Programação de Jogos (Módulo II)

## 📝 O que aprendemos até agora?

Durante o módulo II, focamos no aprendizado de ferramentas essenciais para o desenvolvimento de jogos e organização de projetos, além de linguagens de programação.

### 🛠️ Ferramentas Utilizadas:
- **Godot** (Motor de jogos)
- **Visual Studio** e **Visual Studio Code** (Editores de código)
- **Notion** e **Obsidian** (Organização e documentação)
- **GitHub** (Versionamento de código)
- **Workana** (Plataforma de projetos/freelance)

### 💻 Linguagens de Programação Estudadas:
- **GDScript**
- **C# (CSharp)**
